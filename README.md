Visual Reminder 📱🎯
Overview:
Visual Reminder is an innovative Android launcher designed to help users stay focused without relying on sounds or intrusive notifications. Instead of alarms, the launcher uses animated wallpapers and dynamic app icon changes as gentle visual reminders.
The project is primarily designed for students and anyone who wants to remain productive while still keeping their phone available for important calls and messages.


The Problem:
Many students silence their phones while studying to avoid distractions. However, doing so may cause them to miss important calls or urgent messages.
On the other hand, keeping notifications enabled often leads to checking social media apps and losing focus.
Visual Reminder solves this problem by replacing audio reminders with visual cues that encourage users to return to their tasks without restricting their freedom.


How It Works
The user sets one or more reminder schedules.
When a reminder becomes active:
The device wallpaper plays a reminder animation.
Selected application icons (such as Instagram, YouTube, Facebook, etc.) temporarily change to a block symbol.
If the user taps one of these apps, a reminder dialog appears asking:
"Do you want to open Instagram?"
If the user taps the app again, the application opens normally.
This approach reminds users before they become distracted while allowing them to make the final decision.

Example Use Case:
A student plans to study for 2 hours.
Instead of enabling silent mode, the student activates Visual Reminder.
During the study session:
Calls and messages continue to arrive normally.
When the student unlocks the phone, the wallpaper animation reminds them to stay focused.
Social media apps display a block-style icon as a visual cue.
If the student taps Instagram, a reminder dialog asks if they really want to open it.
Tapping the app again opens it normally.
The launcher encourages mindful decisions rather than forcing restrictions.


Project Philosophy:
Remind, Don't Restrict.
Visual Reminder believes productivity should come from awareness, not forced limitations. Users always remain in control of their device while receiving meaningful visual reminders to stay focused.
